# GitHub Copilot FAQ

## Can I use Copilot from the mobile app?

As of now, GitHub Copilot is **not available** in the GitHub mobile app (iOS or Android).

### Where can I use GitHub Copilot?

GitHub Copilot is currently available in the following environments:

#### GitHub Copilot (Code Completion)
- **Supported IDEs and Editors:**
  - Visual Studio Code (via extension)
  - Visual Studio (via extension)
  - JetBrains IDEs (IntelliJ IDEA, PyCharm, WebStorm, etc.)
  - Neovim (via plugin)
  - Azure Data Studio

#### GitHub Copilot Chat
- **Available in:**
  - Visual Studio Code
  - Visual Studio
  - JetBrains IDEs
  - GitHub.com website (in select interfaces)
  - GitHub CLI (`gh copilot` commands)

#### GitHub Copilot in the CLI
- **GitHub CLI (`gh`):**
  - Use `gh copilot explain` to explain commands
  - Use `gh copilot suggest` to get command suggestions

### Mobile Alternatives

While GitHub Copilot is not available in the mobile app, you can:

1. **Use GitHub Codespaces on mobile browsers**: Access your development environment through a web browser on your mobile device
2. **Use GitHub CLI on mobile terminals**: If you have a terminal app on your mobile device (like Termux on Android), you can use the GitHub CLI with Copilot features
3. **Access GitHub.com on mobile browsers**: Use GitHub Copilot Chat features available on the GitHub website through your mobile browser

### Future Availability

GitHub continues to expand Copilot's availability. Check the [official GitHub Copilot documentation](https://docs.github.com/en/copilot) for the latest updates on supported platforms and features.
